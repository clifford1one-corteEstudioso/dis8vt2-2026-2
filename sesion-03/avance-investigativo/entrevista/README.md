# entrevista

en base al feedback recibido en torno a la rigurosidad de mi investigación, decidí tener una entrevista grabada con un usuario ideal.

la entrevista fue realizada por discord, audio grabado con OBS, y transcrita con Colaborative.

## sujeto

La persona entrevistada es estudiante de producción musical, sube contenido a Instagram regularmente, tanto historias como reels. Utiliza Instagram con propósito de ocio, y también para temas laborales. Promociona su carrera artística, conecta con otros músicos y estudios, y consigue clientes para sesiones de producción.
